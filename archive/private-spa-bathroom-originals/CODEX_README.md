## Non-negotiable presentation rules
1. Use the editorial simplified floor plan ONLY as a visual explanatory diagram. Ground all geometry in original cropped technical source; never add invented dimensions or details.
2. Present the original technical plan and section at zoomable / lightbox size alongside the simplified schematic. They are evidence of work, not decoration.
3. The room is under implementation. Label render `Design Visualisation` and authentic photos `Existing Conditions`. Do not call it `After` until completed photographs exist.
4. Do not publish personal client data; the provided cropped extracts exclude the original title blocks.
5. The clean web presentation uses warm ivory, graphite, restrained muted champagne gold, premium serif/sans editorial spacing.
6. Do not introduce fictional brands, artificial "completed" photography or technical information.
